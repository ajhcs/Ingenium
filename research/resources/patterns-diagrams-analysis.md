## Minimal original workflow candidate for synthesis

When the requested artifact is a diagram, select the representation by the reader's question and authoritative source. Identify the relationships, states, units, order or boundaries it must preserve. Use a table or short text when it communicates the same distinction more clearly. Keep formal notation and supported semantic rendering authoritative; a decorative line, container or crossing never adds engineering meaning.

Adapt only the relevant representation: topology for components and relationships; sequence for actor messages over time; lifecycle/state for one subject's legal changes and outcomes; lanes for ownership and handoffs; a service visibility view for customer-visible versus hidden work; a graph where shared dependencies or cycles make a tree misleading. These are options, not an exhaustive taxonomy or a required order.

For an imported or simplified view, keep the source and a concise account of meaningful aggregates, omissions and unresolved mappings. For a comparison, keep identities and useful spatial anchors steady; distinguish changed meaning, changed relationship endpoints and presentation movement. Check source meaning and final-size readability separately. Deliver editable source, verified requested outputs and the actual coverage limits.

This proposal composes with the existing eight methods and native model traceability. It does not license acquiring templates where references were withheld, replacing project notation, inferring missing semantics, or introducing new user approval steps.

## Evidence limits and validation ideas

No upstream scripts, package installation, generated visual examples, browser interaction tests, or installed-client tests were run. The inventories establish tracked paths and identities; the qualitative matrix is researcher inference from the listed prose. Upstream ADR 0005 reports previously missed example defects and verifier boundaries; this study did not reproduce those defects or verify its fixes. No claim here is documented OpenAI guidance; that comparison belongs to the synthesis owner's separately sourced official guidance.

Potential designed checks for a later original artifact: distinguish a cyclic dependency from a tree; preserve a state guard and cancellation outcome during a redraw; compare the same component renamed versus replaced; expose a backstage failure without treating it as a customer action. These are proposed test cases, not observed evaluation results. The expected benefit is clearer task selection and fewer semantic losses; it has not been measured and does not establish future-model superiority.
