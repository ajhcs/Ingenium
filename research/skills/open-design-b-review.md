# Open Design plugin, scenario and fixture audit (partition B)

Pin: `nexu-io/open-design@8d820a698908dc279ef3d5aeb4ce6d156211a499`, HEAD observed 2026-10-21. Partition B contains every actual SKILL.md outside `skills/`, `design-templates/` and `plugins/_official/examples/`. The accompanying CSV hashes every tracked file under the selected skill directories; every B SKILL body was fully inspected, including the complete Hallmark body in contiguous bounded character slices. Other references, programs, manifests, source templates and assets were inventoried rather than silently treated as read. Two community license files were excerpted, not cleared as complete source-rights audits. No upstream programs, installers or renderers were executed.

The file set includes runnable plugin instructions, protocol atoms, scenario routers, aesthetic template wrappers, contribution tooling and six test/example fixtures. They are not all transferable production skills. A source's `Status: Implemented` statement is documented upstream behavior; this study did not inspect every corresponding daemon implementation or validate it at runtime. No source instruction here was adopted as authority over the study.

## Rights and qualification limits

Root `LICENSE` begins Apache 2.0; the core reader separately audits complete source notices. This reader excerpted nested `plugins/community/hallmark/LICENSE` (MIT, Copyright 2026 Hallmark contributors) and `plugins/community/humanize-ppt/LICENSE` (short MIT declaration, Copyright 2026 LearnPrompt). Multiple source frontmatters declare MIT or Apache 2.0 and name further derived sources. A frontmatter or attribution paragraph is not a substitute for inspecting applicable retained license/NOTICE/asset/font files. Every B directory's tracked support file is included in the inventory, including unreviewed source and rights files. Nothing from those source directories is copied to Ingenium by this research; synthesized recommendations are original prose with pinned credit.

Source wrappers claiming deterministic video outputs, frontend compatibility, native generation or implemented daemon behavior were not run. The research provides no model-scaling forecast, future compatibility certification, measured preference gain or general performance result. Any useful original example is a designed illustration, and any later observed run must be reported separately with exact environment and artifact revision.
