## Eight methods and native model obligations

None of these sources justifies replacing the eight selectable methods or inventing a ninth universal sequence. Structural wireframe can use labels and action semantics (A04–A07); wireflow can show scope/feedback consequences (A08/A10); same-screen states can expose theme/locale/overlay differences without changing canonical model (A01–A03); dense desktop can specify table selection scope (A10); empty/error can refine message persistence (A08); collage can compare vocabulary fragments; palette families can expose role/state/override relationships (A01); fontplate can add locale/numeral text while retaining its fixed-metrics/tuned-fit distinction (A03). These are extensions of existing questions, not a prescribed order.

The shared contract and interaction-sketches were read with all eight leaves. Their stronger native-source contract remains authoritative: exact source/view revisions, stable domain/element IDs, typed model commands, raw vs valid model, acknowledgements and bidirectional requirements coverage. Theme tokens, visible labels, formatted dates and DOM IDs are presentation/binding evidence; they must not fabricate native model entities or make local validity imply Saved. The library docs do not establish SysML semantics, engineering adequacy or user acceptance.
