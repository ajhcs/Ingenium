## Eight methods and native model traceability

All eight method leaves and shared contract were read before comparison. Preserve them as selectable, combinable methods with no ordering: structural wireframe benefits from semantic controls (MUI-01); wireflow and same-screen state sequence retain existing action/state/draft/acknowledgment contracts (MUI-05 is duplicate); desktop workflow may inspect portal scope and focus/activation (MUI-02/06); empty/error retains cause, region, retained work and safe recovery with no added recipe; element collage may compare component fragments without claiming semantic/interaction acceptance; palette families may inspect forced-colors/focus separately (MUI-03), maintaining semantic role equivalence; fontplate retains fixed-metrics versus tuned-fit and actual font evidence, with no MUI font default imposed.

No MUI component API is a native engineering model. For authoritative model-backed work, preserve stable source/requirement/action/state anchors, exact source/view revisions, both-direction coverage, unknown native semantics and external routes. DOM semantics and rendering evidence are additional independent evidence; they do not qualify model meaning, persistence, acceptance or engineering adequacy. No OpenAI guideline compliance or future-intelligence advantage is established by this source. Proposed small reference additions are hypotheses, not observed evaluations.
