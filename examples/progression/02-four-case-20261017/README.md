These are next-user-review preview candidates. Aesthetic work is held for user feedback. Broad stylistic range is unproven: the tranche shares pale grounds/dark text and a constrained font pack. There is no overall novelty, statistical-improvement, accessibility-certification or production-readiness claim. Earlier candidates and frozen delivery preview identities are retained separately; this index does not overwrite or regenerate them.
