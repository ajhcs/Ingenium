# Editable release studies

Original synthetic studies made with Ingenium. These are authored examples, not client work or claims of audience acceptance.

- `cover/cover.svg`: Common Ground publication cover, V3 study.
- `fieldwork/index.html`: Fieldwork responsive interactive website, V2 study. Open in a browser; project cards open dialogs and the pattern control changes the original artwork.
- `identity/identity-sheet.svg` and `identity/open-studio-A3.svg`: Manyfold identity and event application, V3 studies.
- `wayfinding/sources/`: Junction House signs, V3 study. These are design studies; physical installation, legibility at distance and safety compliance have not been established.
- `comparison/`: two historical Common Ground studies, labeled by their own revision. This is a visual comparison, not a controlled performance experiment.
- `first-success/`: a new export from the restored installed helper, with clean and guide sources.

SVG text and paths remain editable. Most SVGs embed selected unchanged font bytes; the matching font files and complete licenses accompany them. Fieldwork loads only its accompanying local fonts. DejaVu is supplied for release graphics. Original artwork and code use the accompanying MIT license. Inter and Fraunces retain their full SIL OFL notices; DejaVu retains its Bitstream/DejaVu notice. No third-party photographs, award images, client logos, private briefs, annotations or interview material are included.

Previews show rendered outputs; design quality and user acceptance are open judgments. The portable plugin can be used without its optional rendering tools. The installed local helper was demonstrated; desktop client discovery remains unverified.
