# Evidence for a design decision

Use this reference when interviews, observations, tickets, surveys or permitted design precedents inform a consequential design choice. Start with the decision and the population or task it concerns. Ordinary prose and existing records suffice.

Keep an observation, a person's report, a stakeholder goal and the author's interpretation distinguishable. Retain enough source context to interpret a claim: participant or segment when known, task and setting, collection period, sample limits and the original passage or result. Mark missing context as unknown. A vivid quote can explain one experience without establishing how common it is.

Check whether apparent corroboration comes from independent sources. Repeated excerpts, summaries or reports of the same event do not add independent observations. Ticket or response counts describe the collected material; they need population and collection context before supporting prevalence claims. Preserve contradictory cases, segment differences and plausible alternative explanations beside the recommendation.

Tie a recommendation to the evidence it uses and state what new observation would change it. Where uncertainty affects a consequential choice, identify a useful next probe or reversible trial. Match the next step to the uncertainty; no fixed theme count, confidence score or research dashboard is needed. Keep an accepted choice distinct from a claim that the supporting interpretation is true.

For a permitted visual precedent, name the qualities to retain, the intentional changes and any source material excluded from adaptation. A precedent can inform a design treatment without establishing user preference, effectiveness or copying rights. Preserve withheld references and the user's existing choices.
