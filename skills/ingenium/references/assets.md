# Optional selected assets

Use metadata search to find a candidate, inspect its source and asset-specific license, then explicitly select one asset. Search strings leave the local environment when network is enabled: use public queries, never private briefs or annotations. Importing this module does not fetch, install, launch a server or write a cache. No collection, font library or registry is downloaded wholesale.

```js
import { createAssetClient } from './src/assets/index.mjs';
const client = createAssetClient({
  allowNetwork: true, // explicit authorized operation only
  parserDir: '/your/existing/parser-install',
  cacheDir: '/your/existing-parent/owned-asset-cache'
});
const results = await client.search({ provider: 'iconify', query: 'window', prefix: 'lucide', limit: 8 });
const detail = await client.details({ provider: 'iconify', id: 'lucide:window' });
// Review detail.license and the actual linked source license before reuse.
const asset = await client.fetch({ provider: 'iconify', id: 'lucide:window', selected: true, outputDir: '/your/existing-parent/new-selection' });
```

This illustrates the API, not a qualified live result. The current qualification is **offline only**. Bounded Iconify and Fontsource metadata reads returned HTTP403 in the qualification environment; live search/details/fetch and live selected-asset rendering remain blocked/not-run. No retry or alternate route was used. Do not infer provider versus intermediary cause. The offline example injects original synthetic responses and assets, labeled `injected-fixture`; it establishes packaging/mechanical behavior, never provider availability or upstream license proof.

The shared client exposes `capabilities()`, `search({provider,query,limit?,prefix?})`, `details({provider,id})`, `preview({provider,id,selected:true})` and `fetch({...selection,outputDir})`. Search returns bounded candidate records and a metadata source hash, not asset files. Details retain provider/id, upstream version label when supplied (otherwise null), exact response hash, concise license/author declaration and supported operations. Preview returns only selected validated SVG bytes for explicit local rendering, without filesystem export. Fetch exclusively creates a new directory with `original.svg`, `safe.svg` and `provenance.json`. Each source/derived file has its own hash; render the derived file. Original SVG remains untrusted source evidence. No output overwrite. Parent directories must already exist without symlink ancestors.

Iconify uses documented `/search` (minimum upstream limit32; local result limit1..32), `/collection?prefix=...&info=true` and selected `/{prefix}/{name}.svg` with numeric24px dimensions. Collection info provides asset-specific license/author/version metadata; a software/provider license is not an asset license. Missing title, SPDX or safe HTTPS license-source URL refuses selected preview/fetch. An upstream declaration still needs applicability and actual license review; it is neither legal advice nor automatic approval. A source hash pins the observed response when the API provides no immutable asset version. Search does not download license URLs. No copied upstream assets are committed.

Fontsource uses documented `v1/fonts?family=...` and `v1/fonts/{id}` metadata. It returns candidate families/variants and available version labels. The documented detail contract does not establish a verified per-file license/package-version binding. Fontsource **preview/fetch remain unavailable**, including when a fixture supplies a license field. This deliberate capability refusal is a limit of this slice. `validateWoff2(bytes)` is only bounded container admission for future consumers; it checks header/ranges, not compressed tables, glyphs, license or render safety, and is not wired to a font download pipeline. No font creation, subsetting, conversion or installation is included.

SVG support requires an explicitly available `saxes`6.0.0 XML parser, resolved locally or only inside the selected `parserDir/node_modules/saxes`; absent/incompatible/load-error outcomes are explicit. It is not installed automatically. An existing installation was reused for qualification. If setting up a separate parser directory is separately authorized, install exact `saxes@6.0.0` there using ordinary npm with scripts disabled. The parser is ISC; its `xmlchars`2.2.0 dependency is MIT. Upstream saxes is archived; this small tested version is an optional capability, not an assertion of ongoing upstream maintenance. Core records/layout/checks remain independent.

The strict static-icon policy uses XML namespace/structure parsing and explicit element/attribute/value allowlists, not regex stripping. It rejects DTD/entities, processing instructions, CDATA, scripts, event handlers, CSS, external resources, links/use/images, foreign namespaces, nested SVG, unsupported text/transforms/paint features and malformed XML. Only bounded geometry and title/description text are retained; comments are omitted from the derived serialization. Unsupported valid icons fail actionably instead of being partially sanitized. This is a narrow policy, not a universal SVG sanitizer or sandbox. Existing general local SVG export behavior is unchanged.

Bounds default to10s per response including body,256KiB metadata,512KiB selected asset,2 redirects,32 cache entries/8MiB cache,2048 XML nodes/24 levels, bounded attribute/path sizes. `limits` can reduce these maxima. URLs are HTTPS with fixed provider hosts/paths; every redirect is manual, revalidated and same-origin. No retry on403/429; errors retain status/Retry-After. Responses must have expected MIME and streamed bytes within limits. Default networking is disabled. Injected transport is trusted caller code, always labeled fixture evidence, and still goes through URL/response checks.

The optional cache is dedicated, flat, exclusive and hash-checked on each read; no path-derived asset names, symlink entries, silent corruption refetch or automatic eviction. Full/locked/unknown/corrupt caches refuse. Use one trusted owner without competing writers; this is not isolation from a malicious process with the same Unix authority. Cache receipts pin observed bytes, not cryptographic publisher authenticity. No cache is created unless selected explicitly. A crash can leave a lock/partial output; preserve evidence and explicitly inspect owned state rather than silently deleting it.

Run `node examples/assets/offline-study.mjs NEW_OUTPUT_DIR EXISTING_PARSER_DIR` from the installed package to exercise the original synthetic MIT icon, metadata, preview, selected fetch, cache and provenance. It writes a responsive HTML technical fixture for separate browser inspection, with system fonts. It performs no network requests. Qualification counts and image inspection are mechanical fixture evidence, not design acceptance.

shadcn remains a metadata extension reference only: [MCP documentation](https://ui.shadcn.com/docs/mcp), [registry index](https://ui.shadcn.com/r/registries.json). No registry installation, code download/execution or component license assumption. unDraw scraping/integration and DiceBear public API are outside this interface.

Primary contracts: [Iconify HTTP API](https://iconify.design/docs/api/), [search](https://iconify.design/docs/api/search.html), [collection](https://iconify.design/docs/api/collection.html), [SVG](https://iconify.design/docs/api/svg.html); [Fontsource fonts](https://fontsource.org/docs/api/fonts), [font detail](https://fontsource.org/docs/api/font-id); [saxes source and license](https://github.com/lddubeau/saxes/tree/v6.0.0). Reviewed for this offline-qualified slice; live provider contracts/assets/licenses remain unverified by the installed client.

## Opt-in redacted request observations

For a future **already authorized** operation, `createAssetClient({captureDiagnostics:true, ...})` enables an in-memory ring of at most8 request records. Read a defensive copy with `client.diagnostics()` after success or failure. Default capture is off. Cache hits do not create a new transport observation. Nothing is written or sent by enabling capture/getting records; there is no retry or change to identity, credentials, routes, permission or request policy.

Schema version1 records UTC `startedAt`, elapsed milliseconds, transport mode (`network`, `injected-fixture`, `disabled`), methodGET, a fixed endpoint category (no URL/path/query/asset ID), last observable stage, allowlisted outcome, `issuingLayer:'unknown'` and at most3 response observations. Each response has hop index/category, numeric HTTP status, allowlisted MIME category, redirect decision, presence booleans for server/via/proxy-authenticate/x-request-id/cf-ray/x-cache, and SHA256 of only that redacted structure. Header values/IDs, raw bodies or their hashes, query names/values/tokens, raw URLs, exception text and environment/proxy/credential values are never part of the capture. The fingerprint groups equivalent observations; it is not a server/body identity or proof of common cause.

Stages are validation, request, response-headers, response-body or complete. A fetch-visible403 demonstrates a response exposed by the transport, not who issued it. A request-stage exception with no response cannot establish CONNECT, TLS, proxy, provider or local-policy attribution. Presence flags may suggest where an authorized owner should look, but cannot identify that layer. Redirects remain manual and validated; observations record whether a redirect was followed after validation or merely observed. Timeout/error snapshots are final copies; they contain no raw exception message.

Only `diagnostics()` is the redacted schema. Existing source provenance and legacy error details remain separate and may contain requested URLs/Retry-After values; they are not a redacted diagnostic export. Do not serialize those fields as if they were this capture. No historical denial can be reconstructed by enabling this later. The current four403s remain unattributed and live qualification blocked; this change authorizes no fresh request.
