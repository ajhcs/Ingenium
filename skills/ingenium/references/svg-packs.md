# Explicit SVG packs

`createSvgPackLibrary({manifestPath,parserDir?})` in `src/catalog/svg-packs.mjs` opens a bounded local manifest. `search({query,category,tag,offset,limit})` pages1..32 metadata records; `categories()` gives frequencies. `inspect({id})` validates only the selected SVG and exact complete notice. `acquire({id,selected:true,customize?,outputDir})` exports separate original, safe, derivative, notice, selection and provenance. `preview({ids,outputDir})` creates a local gallery of1..12 selected assets, each with notices. New directories only; no overwrite, network or install. `refresh()` explicitly clears a library instance's metadata snapshot.

Schema `ingenium-svg-pack/1` has id/title/version/sourceURL/license and entries. Each entry selects a relative file or `{blob:{file,offset,length},sha256}`. Optional upstreamOriginal/normalization records retain source and preparation separately. Availability metadata-only/redistribution-prohibited entries remain browsable and refuse this acquisition route. Per-entry notices may override the pack notice. A source root is one trusted owner's canonical directory, not a race-proof sandbox.

Bounds:8MiB manifest/50000 entries,512KiB selected SVG,64KiB notice/preparation receipt,16MB concatenated blob. Exact hashes and lossless UTF8 required, including BOM preservation. No symlink paths, external resources or broad SVG compatibility. Static icon parser is optional saxes6.0.0. Supported editing reuses package-symbol size/currentColor/explicit existing-stroke controls; no rewriting fixed fills or arbitrary path data.
