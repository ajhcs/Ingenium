# Palette families

**Question:** Which coordinated color roles support the content and intended tone?

Compare a few families using the same role names and small applied sample. Separate canvas, surface, text, accent and semantic feedback where those roles exist. Keep semantic meaning stable across families and give status another cue besides color. Record actual color values and solid-pair measurements when measured. Labels such as warm or restrained describe an interpretation, not a score.

**Review:** Inspect both swatches and the applied content. Check relevant text/background pairs using the [scoped checks](../checks.md), including their composition limits. One contrast pass does not qualify every state, transparency, color-vision need or accessibility requirement. The example palette is a study choice, not Ingenium's required identity.


Keep the full semantic role map and identical specimen. Declare allowed foreground/background pairs and unqualified combinations; written labels or shapes reinforce status. Candidate focus ink against a surface does not qualify a ring beside a dark action, actual ring geometry, or focus/selection distinction. Treat unsupported combinations as not checked rather than deriving a universal palette pass.

Use the [shared study contract](contract.md). Consequential interactions also use [connected sketches](../interaction-sketches.md).
