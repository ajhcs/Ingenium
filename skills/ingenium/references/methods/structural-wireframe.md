# Structural wireframe

**Question:** Can the person find the relevant information and next action?

**Make:** Restrained shapes with the actual text, exposing hierarchy, grouping, navigation, controls and supporting context. Distinguish primary content, editable inputs and annotations. Include a realistic long label or dense item where it matters. Label hidden or collapsed information instead of implying it doesn't exist. Record the target viewport, and map each visible action to its source or to a proposed interaction requirement.

**Review it for:** Ask the person to locate a specific item and describe the likely next action. Check that the intended hierarchy is visible at delivery size and that long labels and dense content still fit.

**Done when:** The hierarchy reads at the target viewport and every visible action has a mapping. Report resizing as untested unless you inspected it separately: a fixed viewport doesn't establish responsive behavior, and a static button has no executed behavior.

Use the [shared study contract](contract.md). Consequential interactions also use [connected sketches](../interaction-sketches.md).
