# Ingenium

**Shape an idea in stages. Keep the work editable.**

Ingenium is a creative skill for Codex and Claude, with a guided route for ChatGPT. Bring a rough idea, a reference, or a design already in progress. Explore its ingredients, make choices about composition and materials, and refine an assembly you can continue to edit.

[Get started](#get-started) · [Explore the process](#a-design-you-can-shape) · [Thirteen studies](#thirteen-studies) · [Client setup](docs/install.md) · [Live demos](https://ajhcs.github.io/Ingenium/)

## A design you can shape

A finished image can hide all the decisions that made it work. Ingenium can make those decisions visible and give you a chance to change them. In these studies, the same idea moves through four views:

1. **Ingredients.** Gather rough, individual components: words, forms, marks, color and other visual fragments. They are material to choose from, not a finished layout.
2. **Composition.** Arrange the content in a neutral structure. Test scale, grouping and emphasis before committing to a visual treatment.
3. **Asset studio.** Develop the pieces the composition needs: imagery, SVG artwork, type and gradients. An asset can be generated, drawn or assembled, depending on the design.
4. **Assembly and refinement.** Bring those pieces together, inspect the result and revise the relationships between them. Keep the source and individual assets available for further work.

These views are a way to make choices together, not a mandatory sequence for every request. Ask for a single study, compare alternatives, or enter with an existing design. The examples below began as vector iterations; the mixed-media explorations and modular asset kits were developed later. The four views organize the work for inspection rather than claiming every artifact was created in that order.

## Try the process

Invoke Ingenium in your client, then adapt this newly written starting prompt to your project:

```text
Use Ingenium to help me develop [describe the artifact and its audience].
The content is: [paste the words or attach the source]. I want it to feel
[describe the mood], while keeping [constraints] intact.

First show rough ingredients I can select from. Then show a neutral
composition that makes the hierarchy clear. Develop the assets separately
where useful, and assemble an editable design from the pieces we choose.
Show each stage and tell me what can still be changed. Ask when a choice
would materially affect the direction. Preserve earlier versions.
```

Then guide a revision with a specific change and a boundary:

```text
Keep the selected composition, wording and imagery. Make the title easier
to read and reduce the visual weight of the supporting details. Save a new
editable revision and show me the result at its intended size.
```

These are reusable prompts written for this README, not transcripts of the historical study sessions. The study pages link to recorded image-generation prompts where they exist; a vector-only study may have no image-generation prompt.

## Get started

The creative guidance needs no Node runtime, server or API key of its own. Your client supplies the model and file tools. The optional terminal installer uses Node/npm; [manual installation](docs/install.md#manual-install-without-node) does not.

### Codex app or CLI

Run in the project where you want to use Ingenium:

```sh
npx skills@1.7.2 add ajhcs/Ingenium --skill ingenium --agent codex
```

Open a fresh Codex conversation in that project, confirm Ingenium appears in the skill picker, and invoke **`$ingenium`** with your brief.

### Claude Code

Run in your project:

```sh
npx skills@1.7.2 add ajhcs/Ingenium --skill ingenium --agent claude-code
```

Start Claude Code there, check `/skills`, and use **`/ingenium`** with your brief. Both commands use the third-party [Vercel skills installer](https://github.com/vercel-labs/skills) and install project-local guidance. Review its prompt before confirming; it can replace an existing skill of the same name. See [update, remove and troubleshooting](docs/install.md#update-or-remove).

### ChatGPT

Without custom skill upload, copy the [Ingenium instructions](skills/ingenium/SKILL.md) into your conversation, then add your brief. If a named reference is needed, attach that file from the [guidance ZIP](https://github.com/ajhcs/Ingenium/raw/refs/heads/main/site/assets/downloads/ingenium-skill.zip). This uses the instructions in that conversation; it does not install a persistent skill.

If your workspace has custom Skills enabled, use **Plugins → Skills → Create → Upload from your computer**. Do not assume a personal Pro subscription includes this feature. See [workspace eligibility and setup](docs/install.md#chatgpt).

### Claude chat

[Download the guidance ZIP](https://github.com/ajhcs/Ingenium/raw/refs/heads/main/site/assets/downloads/ingenium-skill.zip), then go to **Customize → Skills → + → Create skill → Upload a skill**. Upload the ZIP, enable Ingenium and start a new chat with “Use Ingenium.” Code execution and file creation must be enabled. See [Claude chat setup](docs/install.md#claude-chat).
