The shipped explicit package acquisition command verifies exact metadata/distribution/SHA512 before bounded data extraction, without executing package scripts. The shipped item-preparation command consumes already acquired selected data and rights evidence offline. Missing sources or optional tools refuse/report acquisition required rather than silently downloading or substituting. No installed agent-client integration is implied by source tests or local command use.

The original four worked studies used DejaVu and authored vectors. They did not use these acquired libraries or the earlier original-font/vector-boolean pipeline. An asset-enabled follow-on evaluation must preserve those baseline briefs and outputs and use fresh producer contexts; technical library qualification alone does not establish improved design outcomes.
