## Gap decisions

The complete considered gap matrices remain in the source reports: [UI-UX](../research/skills/ui-ux-review.md), [Open Design plugin partition](../research/skills/open-design-b-review.md), [Ant/MUI](../research/components/README.md), [patterns/diagrams](../research/resources/patterns-diagrams-analysis.md), and [fonts/resources](../research/resources/resource-analysis.md). Rows retain exact pinned evidence paths, baseline comparisons, applicability, expected benefit, cost, duplication and rejected alternatives. Several source rows converge on one mechanism; there is no adoption quota.

| Integrated mechanism | Why it adds something | Cost and rejected alternative |
| --- | --- | --- |
| Optional presentation contexts | Relates source authority, semantic roles, inherited/local scope and locale-dependent projections. Preserves typed meaning, unit symbols and equal-value tokens with distinct roles | Two routing rows plus a conditional leaf. No mandatory token schema, migration, MASTER file, palette identity or internationalization project |
| Optional diagram meaning | Selects relationships, messages, lifecycle, handoffs, visibility or time by the reader's question, with concise import/omission accounting | Conditional leaf, no ninth study method, diagram taxonomy engine, template library, fixed layout or universal redraw |
| Scoped web component guidance | Names semantic root/label/help/error relationships and forced-colors/clipped-focus evidence after visual substitution | Small addition to the existing UI leaf; no framework, DOM requirement imposed on native desktop products or full accessibility claim |
| Terminal/icon font specimen extension | Names symbol codepoints/ligatures, neighboring text and advance/cell/clipping context absent from an ASCII-only proof | Small addition to the existing fontplate; no new font binary, registry, renderer, acquisition route or global install |

Existing exploration, measured composition, editable originals, truthful exports, user-choice continuity, recovery, draft/model/persistence separation, stable subject identity and native bidirectional traceability remain. Eight methods stay optional and composable. Broader brand strategy, crop/platform catalogs, API generators, framework recipes, whole component systems and general Java pattern machinery were deferred or rejected where they add duplication, scope or maintenance without a demonstrated gap. Aesthetic bans, numerical taste scores, arbitrary agent counts, rigid questionnaires and mandatory workflow sequences were rejected.
