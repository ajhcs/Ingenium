# Fresh V4 design pilot

Four fresh producers completed the original fictional cover, responsive website, flexible identity/poster and visitor-wayfinding briefs using the purpose-refined Ingenium instructions. Each first complete output was frozen before independent review. The comparison gallery preserves Native → v1 → original v2 → fresh v3 → V4; corrections remain separately labelled.

## Frozen inputs and execution

All four used GPT-6.1-Sol, medium effort and Default mode, confirmed from actual session contexts. They received unchanged original brief bytes, the same qualified resource catalog/tool configuration, the installed skill and the separate conceptual-only composition reference read directly. Prior designs, feedback, participant material, award references, full templates and actual worked-example files were withheld.

Reviews address correctness within stated viewing conditions; they do not declare aesthetic superiority or user acceptance.

## Limits

These are digital synthetic studies. Physical print, installed desktop-editor/client behavior, assistive-technology coverage, cross-browser behavior, representative-reader comprehension, real-distance sign readability and engineering adequacy remain unqualified. Optional Python WOFF2 metadata decoding was unavailable because Brotli was absent; browser text-run font identity and visible glyphs were checked instead. No dependency installation was needed for this run.

No runtime module, dependency manifest, lock or instruction file changed for this pilot report, and no broad library suite was rerun. Earlier package qualifications remain historical evidence. No merge, release, deployment or administration is included. V5 remains pending recovery of the original award-reference mappings; no substitute references were introduced.
